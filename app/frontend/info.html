How the tutor works

The AI tutor analyses your uploaded lesson plan and offers structured feedback in categories such as didactical approaches, skills, curriculum connections, potential challenges, and opportunities.

The tutor uses the lesson plan text to identify relevant teaching methods and suggest improvements. It keeps the workflow transparent and explains why each suggestion is made.

Uploaded lesson plans are processed locally by the server, and the tutor only uses the contents of the document for analysis. Data storage is limited to the local project folder and can be deleted at any time.

🚀 First-time setup

1

📁 Get the tutor

Download and extract the complete project folder. Do not remove files from the folder.

2

▶️ Start it

On Windows, double-click start_tutor.bat. On macOS, double-click start_tutor.command. On Linux, run start_tutor.sh.

3

🔑 Add your API key

On the first start, open Admin settings, enter the Mistral API key, and select Save settings.

4

✅ Start working

Return to the start screen and select I understand and want to proceed.

🧭 Your tutor workflow

📝

1. Describe your lesson

Choose the country, subject, age or grade range, and upload a PDF, DOCX, or TXT lesson plan.

🔎

2. Review the analysis

Read the strengths, challenges, curriculum connections, and suggested focus points.

💬

3. Refine the plan

Answer the tutor's questions or use the quick replies. Your decisions update the lesson-plan preview.

⬇️

4. Download the result

Review the final draft and download it as a DOCX or PDF. Exports are saved locally.

💡 What you need Internet access is required for the first setup, package installation, and Mistral AI requests. Windows can install Python automatically when winget is available. On macOS and Linux, install Python 3.11 or newer first if it is not already installed.
🔒 Your data and API key The API key is stored locally under app/server/mistral_api_key.txt and is not committed to Git. Uploaded lesson plans, logs, and exports remain in the local project folder.

# How to Install and Start the STEAiM-CT AI Tutor

## Step 1: Install Python

Download and install **Python 3.11 or 3.12** if Python is not already installed on your computer.

Select the appropriate version for your operating system:

- **Windows:** [Download Python 3.12](https://www.python.org/ftp/python/3.12.3/python-3.12.3-amd64.exe)
- **macOS:** [Download Python 3.12](https://www.python.org/ftp/python/3.12.3/python-3.12.3-macos11.pkg)
- **Linux:** [Download Python 3.11](https://www.python.org/ftp/python/3.11.13/Python-3.11.13.tgz)

Follow the installation instructions for your operating system and allow the installation when prompted.

**Windows users:** Make sure to select **"Add Python to PATH"** during installation.

## Step 2: Download the AI Tutor

1. Open the [STEAiM-CT AI Tutor GitHub repository](https://github.com/uinselchen/steaim-ct-tutor/tree/codex/safe-daniel-refactor).
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Save the ZIP file to your computer.

## Step 3: Unzip and Start the Tutor

1. Extract the downloaded ZIP file.
2. Open the extracted folder.
3. Locate the start file for your operating system:

   - **Windows:** `start_tutor.bat`
   - **macOS:** `start_tutor.command`
   - **Linux:** `start_tutor.sh`

4. Double-click or execute the corresponding file.

The Tutor will automatically install the required components.

**Note:** Your operating system may ask you to confirm the installation or allow the application to run. Review and approve the necessary permissions.

## Step 4: Enter Your Mistral API Key

After successful installation, the Tutor will open in your web browser.

1. An administrative settings pop-up will appear.
2. Locate the **Mistral API key** field at the bottom of the Tutor.
3. Enter the API key provided to you by the project team.
4. Click **Save** to store the key.

**Important:** The API key is provided exclusively for using the STEAiM-CT AI Tutor. Do not share it or use it for other purposes.

Once the API key has been saved, the Tutor is ready to use.
